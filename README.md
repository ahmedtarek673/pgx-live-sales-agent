# PGX Live Sales Agent

A voice-enabled conversational sales-agent prototype for PGX Agency, designed for real-time customer conversations and Egyptian-market interactions.

## Highlights

- Real-time conversational interface
- Voice input and response states
- PGX-branded user experience
- Environment-based API configuration

## Getting started

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local`.
3. Add the required API key locally.
4. Start the development server with `npm run dev`.

Never commit `.env.local` or API keys.
